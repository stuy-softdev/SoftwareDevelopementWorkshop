## DISCOVERIES
- Make sure to use double curly brackets ("{{ }}") for the fields being replaced in HTML template
- Import render_template!(So: ```from flask import Flask, render_template)```
- Links in HTML reminder: ```<a href="url">link text</a>```
- When you pass info in the fields, you can use  ```| safe``` to get rid of automtic escaping.
