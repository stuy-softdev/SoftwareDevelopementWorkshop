## 2. Core Syntax
### 2.1 Variables & Types
- [✅] `int`, `float`, `str`, `bool`, `None`
 - int -> integer Variable; x = 100
 - float -> floating point (int with decimal point); y = 100.0
 - str -> string (text); goat = "Jacob"
 - bool -> True or False; Jacobisgoat = True

- [✅] `type()`, `isinstance()`
 - type -> returns type of a variable; type(goat) -> <class 'String'>
- [ ✅ ] Type conversion: `int()`, `str()`, `float()`
 - type conversion -> converts types; str(5) -> "5"
### 2.2 Strings
- [✅] f-strings
    - Allows you to place variables in strings in an easy manner.
    - f"User is {age} years old."
    - Errors in fstring will cause errors everywhere. (Unclosed bracket? Program boom.)
- [✅] Common methods: `.strip()`, `.split()`, `.join()`, `.lower()`, `.replace()`, `.startswith()`
    - Basic operations on strings.
        - `.strip()`: Removes whitespace from the start and end of a string. You can pass it an argument of what to count as whitespace.
        - `.split()`: Takes in a character sequence and splits the string at every instance of that sequence.
        - `.join()`: Takes in strings and puts the string between them.
        - `.lower()`: Turns all the characters lowercase.
        - `.replace()`: Turns one given string in to another.
        - `.startsWith()`: Checks if the string starts with another.
    - Ex:
        - `.strip()`: `"         asdf                  ".strip()` -> `"asdf"`
        - `.split()`: `"ababcababab".split("c")` -> `["abab", "ababab"]`
        - `.join()`: `", ".join(["hi", "hello", "boo"])` -> `"hi, hello, boo"`
        - `.lower()`: `"AAAAAH im ok now".lower()` -> `"aaaaah im ok now"`
        - `.replace()`: `"i love chocolate ice cream".replace("chocolate", "vanilla")` -> `"i love vanilla ice cream"`
        - `.startsWith()`: `"aab".startsWith("aa")` -> `True` && `"aab".startsWith("bb")` -> `False`
    - They return new variables, not modify the old ones.
- [✅] Slicing
    - Take a smaller part of a string using the indices.
    - `"abcd"[0:1]` -> `"a"` && `"abcd"[2:]` -> `"cd"`
    - No guarantees any part of what you're getting exists.
- [✅] Multiline strings (`"""`)
    - Define a string over multiple lines
    - `"""
        hi
        this is very long
    """`
    - May look weird within python formatting

### 2.3 Operators
- [✅] Comparison: `==`, `!=`, `<`, `>`
    - Use to compare the value of integers and returns a boolean.\
    - e.g `Print(5 == 6) --> False Print(8 < 9) --> True`

- [✅] Logical: `and`, `or`, `not`  
    - Use to determine the value of one or more booleans in multiple ways.
    - e.g `a = True b = False c = True Print(not a) --> False Print(a and b) --> false Print(b or c) --> True`

- [✅] Identity/membership: `is`, `is not`, `in`, `not in`
    - Use is and is not to compare objects identity. \
    - e.g `a = "hi" b = "hi" Print(a is b) --> False Print(a is not b) --> True`
    - Use in and not in for checking if a value is in a list. `e.g a = [1] b = 1 Print(b in a) --> True Print(b not in a) --> False`

- [✅] `==` vs `is`
    - Use == for comparing value and is for comparing objects.
    - e.g `a = 2 b = 2 Print(a == b) --> True Print(a is b) --> False`

## 3. Control Flow``````
- [✅] `if` / `elif` / `else`
    - Used to make or not make a certain thing happen based on conditions of a variable.\
    - e.g. `if(a == b): return 0 elif(a > b): return a - b else return b - a.`

- [✅] `for` loops, `range()`, `enumerate()`, `zip()`
    - `Use enumerate()` to iterate through a list and provides the index and value.
    - e.g. `a = ["Python", "Java", "C++"]
            for i, v in enumerate(a):
                print(i, v)
            --> 0 Python 1 Java 2 C++`
    - `zip()` is used to combine lists
    - e.g. `a = [1, 2, 3]
           b = ['a', 'b', 'c']
           print(list(res))
           --> [(1, 'a'), (2, 'b'), (3, 'c')]`

- [✅] `while`, `break`, `continue`
    - while is used to make a statement repeat while a certain condition is True
    - e.g. `while (x < 10):
              Print(x)
              x += 1`
    - break is used to stop a while loop on a certain condition.
    - e.g. `while (x < 10):
              Print(x)
              if (x == 5): break # exit loop when x = 5
              x += 1`
    - continue is used to skip the rest of the individual iteration of a loop
    - e.g. `while (x < 10)
              if (x == 5): continue # Doesn't print 5
                x += 1`

- [✅] `pass`
    - A command that is null and does nothing. Often used to not cause a syntax error for a defined function without code.
    - e.g. `def NotCodedFunction(): pass`

- [✅] Ternary expression: `x if cond else y`
    - Shortened if statement. x (this result) if cond (this is true) else y (alternate result)
    - e.g. `parity = "even" if (a % 2 == 0) else parity = "odd"`

## 4. Data Structures
| Structure | Literal | Key methods | Web-dev use case |
|-----------|---------|-------------|------------------|
| `list` | `[]` | `.append()`, `.pop()`, `.sort()` | Rows from a query |
| `dict` | `{}` | `.get()`, `.items()`, `.update()` | Form data, JSON |

- [✅] Comprehensions (list, dict, set)
    - list comprehension -> builds a list more easily; goats = ["jacob" + "goat" for x in range(5)] -> ["jacobgoat", "jacobgoat", "jacobgoat", "jacobgoat", "jacobgoat"]
     - dict comprehension -> builds a dict more easily; lengths = {"saxon": x for x in range(5)} -> {"saxon": 1, "Saxon": 2, "Saxon" : 3, "Saxon": 4, "Saxon": 5}
     - set comprehension -> builds a set more easily; letters = {c for c in "676767"} -> {"6", "7"}

- [✅] Unpacking (`a, b = ...`, `*args`)
    - unpacking -> splits a list into separate variables; a, b = [1, 2] -> a =1, b = 2
    - *args -> lets a function take a number of arguments; def total(*args): return sum(args)

- [✅] Sorting: `sorted()`, `key=`, `reverse=`
    - sorted() -> sorts a list; sorted([3, 1, 2]) -> [1, 2, 3]
    - key= -> sorts by a function (keyword only); sorted(["bb", "a", "ccc"], key=len) -> ["a", "bb", "ccc"]
    - reverse= -> sorts backwards (keyword only); sorted([3, 1, 2], reverse=True) -> [3, 2, 1]
- [✅] Mutability and copying (`.copy()`, `copy.deepcopy`)
    - mutable -> can be changed after it's made (list, dict, but tuple isn't); nums = [1, 2]; nums.append(3) -> [1, 2, 3]
    - .copy() -> makes a new copy of list/dict; b = a.copy()
    - copy.deepcopy() -> copies everything, including lists inside lists; deepcopy(a)

## 5. Functions & Structure
- [✅] `def`, `return`, default args, keyword args
    - `def` defines a function
    - `return` allows the function to return a value
        - ```python
        def add2(a, b):
            return a + b```
    - You can add an equals after the name of an argument _while defining_ in
        order to give it a default. Then, if, when calling, you don't provide
        that argument, it becomes the default. (default args)
        - ```python
        def add2(a=1, b=1):
            return a + b

        add2(0, 0) # 0
        add2(5) # 6
        add2() # 2```
    - You can add an equals after the name of an argument _while calling_ in
        order to change argument out of order. (keyword args)
        - ```python
        def add2(useless, why, nothing, noimportance, junk, a, boo, aaaahhh, b):
            return a + b

        add2(a=1, b=4) # 5```
    - Do not confuse default args and keyword args. Key is when the equals
        sign is. Default -> Declaration, Keyword -> Call.
- [✅] Docstrings
    - Add documentation with a multiline string right after the function declaration.
        - ```python
        def add2(a, b):
            """Adds two numbers."""
            return a + b```
    - Not:
        - ```python
        """Oops I suck at docstrings :("""
        def add2(a, b):
            return a + b```
- [✅] Type hints (`def f(x: int) -> str:`)
    - Tells you what type is expected.
    - ```python
    def add2(a: int, b: int) -> int:
        return a + b```
    - Is not enforced. If you still pass it the wrong type, it will error.
- [✅] `lambda`
    - Quick, small, nameless function.
    - `lambda a, b : a + b`
    - Can only have in it one expression. Nothing complicated.
- [✅] Modules and `import` / `from ... import ...`
    - Split functions up into multiple files.
        - Ex:
        - ```python
        """adder.py"""

        def add2(a, b):
            return a, b```
        - ```python
        """main.py"""

        import adder

        adder.add2(1, 2)```
        - Or only one function:
        - ```python
        """main2.py"""

        from adder import add2

        add2(1, 2)```
    - If using just `import`, you need to add the name of the file still.
- [✅] `if __name__ == "__main__":`
    - Code under this special if only runs when the file is run normally, and
        not when it is added a module.
    - ```python
    def add2(a, b):
        return a + b

    if __name__ == "__main__":
        print(str(add(1, 2)) + " is 1 + 2")```
    - Without this, your modules will run ALL code in them when imported.

## 7. Errors, Files & Resources
### 7.1 Exceptions
- [✅] `try` / `except` / `else` / `finally`
    - Used for code that could cause errors.
    - The try block includes the sensitive code
    - except block says what to do for a specific error
    - else block says what to do if there are no errors
    - finally block for what to do at the end no matter what
    - e.g. `try:
                num = int(input("Enter a number: "))
                result = 100 / num
            except ValueError:
                  print("You didn't enter an integer.")
            else:
                print("The result is", result)
            finally:
                print("Program finished.")`

- [✅] Common exceptions: `ValueError`, `KeyError`, `TypeError`, `FileNotFoundError`
    - ValueError is when the input content can't be handled. See above example
    - KeyError is when you try to access a key that doesn't exists
    - e.g. `student = {"firstName": "John", "lastName": "Doe"}
           try: print(student["middleName"]) except KeyError: print("key doesn't exist")`
    - TypeError is when an input is the completely wrong type.
    - gotcha: A ValueError can occur with the correct type such as dividing by zero
    - e.g. `try: multiply = "hi" * "hi"
            except TypeError: print("can't multiply strings")`
    - FileNotFoundError for when you try to open a file that does not exists
    - gotcha: the file must be in the same directory if opened directly or you can write out the path to the file.
    - e.g. `try: open(thisFileDoesNotExist.py, "w")
            except FileNotFoundError: print(file doesn't exist)`

#### CSV
    - [✅] `import csv`; the `newline=""` argument
    - import csv -> imports csv library
    - newline="" -> stops extra blank lines from showing up between rows
    - [✅] `csv.reader`
    - csv.reader -> reads each row as a list of strings; for row in csv.reader(f): print(row) -> ["Jacob", "goat"]
    - [✅] `csv.DictReader` and `.fieldnames`
    - csv.DictReader -> reads each row as a dictionary; for row in csv.DictReader(f): print(row) -> {"name": "Batuhan", "status": "goat"}
    - .fieldnames -> list of the column names from the header row; reader.fieldnames -> ["name", "status"]
    - [✅] `csv.writer` and `csv.DictWriter`: `.writeheader()`, `.writerow()`, `.writerows()`
    - csv.writer -> writes lists as row as csv format; w = csv.writer(f)
    - csv.DictWriter -> writes dicts as csv format, w = csv.DictWriter(f, fieldnames=["name", "status"])
    - .writeheader() -> writes the column names as the first row; w.writeheader() -> name,status
    - .writerow() -> writes one row; w.writerow(["Jacob", "goat"]) -> Jacob,goat
    - .writerows() -> writes many rows at once; w.writerows([["Jacob", "goat"], ["Saxon", "goat"]])
    - [✅] Type conversion of CSV values
    - type conversion -> everything in a CSV is a string, so convert it normally
    - [✅] `delimiter=` for non-comma files
    - delimiter= -> tells csv what separates the values (comma is default, but use this otherwise); csv.reader(f, delimiter="\t")
    - [✅] Gotcha
    - gotcha -> numbers come back as strings
